## Known issues to fix

### Quality (by ear)
- [ ] **Pauses at sentence ends:** over the full 15 min, the English has 225 s of silence vs 94 s in the original, ja 265 s, zh 233 s. The translations are naturally shorter than the source. Options: lengthening pass + speed tuning + let the next sentence start early.
- [ ] **ja/zh TTS sometimes slips into Korean** (the agent catches it and re-translates/re-synthesizes, but it costs time). Look into fixing it at the source, e.g. a short language cue.
- [ ] Some translations are still a bit wordy or stiff (e.g. "It is now." ← "이제 그렇습니다"). Revisit the prompt.
- [ ] The original video has burned-in Korean captions, which overlap our subtitles.

### Operations
- [ ] A worker killed for running out of memory (SIGKILL) leaves the job showing "running". The UI should treat a "running" job with no update for N minutes as failed.
- [ ] Gemini text calls sometimes get rate-limited (one run took 12 minutes because of it). Retries are now logged.
- [ ] Downloading a 3-minute video on Cloud Run takes ~1 min (through the Webshare proxy, which uses its bandwidth).
- [ ] 3 min × 3 languages: 2:52 locally vs 6:30 on Cloud Run. Speed it up (more CPU or parallelism).
